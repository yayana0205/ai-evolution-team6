\# \[SoleMate / RunFit] 제품 명세서 (Specification)



\## 1. 개요

사용자의 신체 조건, 러닝 퍼포먼스, 대회 환경을 기반으로  

최적의 러닝화를 추천하는 데이터 기반 시스템



\---



\## 2. 사용자 입력 (Input)



\### 필수 입력

\- 나이

\- 성별

\- 발 모양 (이집트형, 그리스형, 로마형 등)

\- 발폭 (좁음, 보통, 넓음)

\- 발 유형 (내전, 중립, 외전)

\- 예산



\### 선택 입력

\- 선호 브랜드

\- 러닝 기록 (예: 10km 시간)

\- 참가 대회



\---



\## 3. 핵심 기능



\### 3.1 기본 추천 엔진

\- 사용자 조건 기반 신발 필터링 및 추천



\---



\### 3.2 퍼포먼스 기반 추천

\- 빠른 러너 → 반발력/카본화

\- 느린 러너 → 쿠셔닝 중심



\---



\### 3.3 대회 기반 추천

\- 평지 코스 → 경량화 신발

\- 업다운 코스 → 안정성/쿠션 강조



\---



\### 3.4 설명 가능한 추천

\- 추천 이유 제공



예:

“발폭 넓음 + 과내전 → 안정화 신발 추천”



\---



\## 4. 데이터 소스



\### 외부 데이터

\- 무신사, 네이버, SSG 등 이커머스

\- 유튜브 리뷰 및 댓글



\### 내부 데이터 (향후)

\- 사용자 피드백

\- 러닝 기록 데이터



\---



\## 5. 추천 로직



\### Step 1: 필터링

\- 조건에 맞지 않는 신발 제거



\---



\### Step 2: 점수화

\- 착용 적합도

\- 퍼포먼스 적합도

\- 가격 적합도



\---



\### Step 3: 랭킹

\- 상위 N개 추천



\---



\## 6. 기술 접근 방식



\### 1단계 (MVP)

\- 규칙 기반 시스템



\### 2단계

\- 콘텐츠 기반 추천



\### 3단계

\- 머신러닝 적용 (Random Forest 등)



\---



\## 7. 출력 결과

\- 추천 러닝화 Top 3\~5

\- 추천 이유

\- 가격 정보

\- 구매 링크 (향후)



\---



\## 8. 확장 기능

\- 러닝 앱 연동 (예: Strava)

\- 부상 예측

\- 맞춤형 러닝 코칭
