\# \[SoleMate / RunFit] 사전 실패 분석 (Premortem)



\## 가정: 1년 후 프로젝트는 실패했다.



왜 실패했는가?



\---



\## 🚨 1. 데이터 품질 문제

\### 문제

\- 리뷰 데이터가 감정적이고 편향됨

\- “좋은 신발”에 대한 정답 데이터 부재



\### 영향

\- 추천 정확도 저하

\- 사용자 신뢰 하락



\### 대응 전략

\- 감성 분석 적용

\- 신뢰도 기반 가중치 부여

\- 사용자 피드백 데이터 축적



\---



\## 🚨 2. 콜드 스타트 문제

\### 문제

\- 초기 학습 데이터 부족

\- 추천 품질 낮음



\### 영향

\- 초기 사용자 이탈



\### 대응 전략

\- 규칙 기반 시스템으로 시작

\- 전문가 지식 기반 룰 적용



\---



\## 🚨 3. 사용자 신뢰 부족

\### 문제

\- “신발은 직접 신어봐야 한다”는 인식



\### 영향

\- 서비스 사용률 저하



\### 대응 전략

\- 추천 이유 설명 기능 제공

\- 투명한 로직 공개



\---



\## 🚨 4. 차별성 부족

\### 문제

\- 일반 추천 서비스처럼 보임



\### 영향

\- 경쟁력 부족



\### 대응 전략

\- 대회 코스 기반 추천 강조

\- 퍼포먼스 향상 중심 설계



\---



\## 🚨 5. 데이터 확보 실패

\### 문제

\- 구조화된 데이터 확보 어려움



\### 영향

\- 모델 발전 정체



\### 대응 전략

\- 공개 데이터 활용

\- 사용자 입력 데이터 확보



\---



\## 🚨 6. 수익 모델 부재

\### 문제

\- 추천 기능만으로 수익 창출 어려움



\### 영향

\- 서비스 지속 불가



\### 대응 전략

\- 제휴 마케팅 (Affiliate)

\- 프리미엄 추천 서비스



\---



\## 🎯 결론

성공을 위한 핵심 요소:

\- 데이터 품질

\- 설명 가능성

\- 사용자 피드백 루프
