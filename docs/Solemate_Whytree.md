\# \[SoleMate / RunFit] Why Tree 분석



\## 핵심 질문

왜 데이터 기반 러닝화 추천 서비스가 필요한가?



\---



\## 1단계: 왜?

사용자들은 러닝화를 선택하는 데 어려움을 겪는다.



\---



\## 2단계: 왜?

현재 정보는 신뢰도가 낮다.

\- 블로그 → 주관적

\- SNS → 광고성

\- 리뷰 → 일관성 부족



\---



\## 3단계: 왜?

개인화가 이루어지지 않는다.

\- 발 구조 반영 없음

\- 러닝 능력 반영 없음

\- 환경 요소 반영 없음



\---



\## 4단계: 왜?

문제를 단순 “제품 선택”으로 보기 때문이다.



하지만 실제로는:

→ \*\*퍼포먼스 최적화 문제\*\*



\---



\## 5단계: 근본 원인

데이터 기반 의사결정 시스템 부재



\---



\## 해결 방향



문제 → 해결



\- 주관적 정보 → 데이터 기반 분석

\- 개인화 부족 → 사용자 프로파일링

\- 퍼포먼스 무시 → 기록 기반 추천

\- 환경 미반영 → 대회 코스 반영



\---
